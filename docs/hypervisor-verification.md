# Hyper-V・VMware・VirtualBox での共同 VM 検証（2026-10-11）

## 状態と対象

- **状態**: AlmaLinux 10.2 の x86_64 VM で実行した共同検証の横断報告
  - 初期設定の AS1〜AS4 は、Hyper-V・VMware Workstation Pro・VirtualBox の 3 方式で実施した
  - CL1〜CL5、R1〜R7、N1、FXA・FXB は、主に Hyper-V で対象範囲を判定した。失敗・代替操作・途中中断・認証前で止めた範囲を含む
  - 正式 3 巡の性能測定は進行中で、数値と方式間の性能の結論は未完成

この文書は、既存証跡に基づく結果の一覧。実行するときは各手順書を使い、個別の範囲は対応する `verification/` の記録を参照する。[2026-10-06 の VM 検証](almalinux-vm-verification.md)とは別の試験で、過去の成功・失敗を今回の結果に置き換えない。

表の手順数・成功数・失敗数と環境の値は、担当の `result.md` または既存の検証記録から転記した**報告由来**の値。本報告の作成では、一次の端末ログ・PNG・測定ファイルと再照合していない。未照合の集計を一次証跡で確定した数値とは扱わない。

## 方法と比較範囲

手順書のブロックを、主に SSH の対話の bash に 1 つずつ貼り、出力と成功条件を照らし合わせた。GNOME の端末を使う前提の手順でも、通常の貼り先は SSH。GUI はコンソールへのキー送信と PNG、TUI は端末の文字・キー応答・終了で判定した。IBus・クリップボード・ブラウザのように画面セッションを要する箇所は、コンソールの端末での結果を分けて記録している。

Syncthing のブラウザは相手 VM のコンソール上の Firefox、Forgejo は相手 VM のヘッドレス Firefox を、Marionette で自動操作した。DOM の文字と PNG を使う判定を含み、人がすべての画面を操作した確認とは区別する。

| 比較する範囲 | 今回確かめたこと | 比較に含めないこと |
|---|---|---|
| 3 方式の AS1〜AS4 | 同じ初期設定の項を順に進めた際の到達点、共通の不具合、ファームウェア等の環境差 | 厳密に同一の CPU・ディスク条件、すべてをデスクトップ端末だけで実行した結果 |
| CL・R の後続手順 | 主に Hyper-V での導入、設定、GUI・TUI、通信、指定された更新・復元 | VMware・VirtualBox での同じ後続手順の通しと、方式間の成功率 |
| N1 と FXA・FXB | 仮想化拡張を公開した Hyper-V での起動、修正箇所と指定した撤去の確認 | 内側 OS の導入完了、全方式での修正後の初期設定の通し |
| 性能 | 正式測定の作業が進行中であること | 初期設定の作業時間を性能値にすること、未完成の測定からの順位付け |

表の「成功」は担当報告の「通した」に対応し、一部だけの確認や代替操作を含む。「失敗」は本文の成功条件を満たさなかったもの。「条件未該当」は条件に当たらず飛ばした手順で、成功には数えない。「未実施」は認証・機器・許可・範囲などの理由で完了を確認していないもの。

単位の分母には参照先の手順、再確認、修正後の試験が重なるため、**単位表を合算した総手順数・総成功率は出さない**。C14 と C15 は R6 の中断と再開、C18・C19 は既存証跡の文書化であり、新しい試験単位として足さない。
